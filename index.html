🧠 openmymemo - Your AI Memory You Actually Own

openmymemo keeps everything your AI assistants remember about you inside a single folder on your own computer. Claude, Codex, Cursor and any other app that speaks MCP can all read and write to that same folder. You can open it, read it, edit it, and undo any change you do not like.

Free for Windows · No account required · Your data never leaves your PC

What Is openmymemo?

Most AI assistants remember things about you, but they keep those memories locked inside a service you cannot see. You cannot open the file, you cannot read what was written, and you cannot delete a single wrong detail without wiping everything.

openmymemo changes that. It turns your AI memory into an ordinary folder of plain text files that sits on your own hard drive. Every note, preference, project detail and past conversation summary is written into that folder as a normal document you can open in any text editor. Nothing is hidden. Nothing is encrypted behind a login you do not control.

Because the memory lives in a shared folder instead of inside one app, every AI tool you use sees the same picture of you. Start a conversation in Claude Code on your desktop, continue it in Cursor, then ask Codex the same question, and all three already know the context. You do not have to repeat yourself, and you do not have to copy and paste notes between tools.

The folder is yours in the plainest sense. Back it up by copying it. Move it to a new drive. Open it in Obsidian. Search it with the same tools you already use for documents. If openmymemo disappeared tomorrow, your memory would still be there, readable and complete.

🚀 Set Up in a Few Clicks

  1. Choose where your memory folder lives. On your first launch, openmymemo asks which folder should hold your memories. The suggested location inside your user folder is a good choice, and you can change it later. Click Create to build the folder.
  2. Let openmymemo set itself up. The application prepares the folder structure and adds a small connection file that lets other apps find your memory. This happens automatically in a few seconds. A green check mark means it finished successfully.
  3. Connect your first AI app. Openmymemo shows a short connection setting for each supported app. Use the Copy button next to the app you want, paste the setting where the app asks for it, and restart that app. That is all the setup there is.
  4. Start a conversation. Open your AI app and ask it something it would need memory for, such as "what am I currently working on?" It will read your folder and answer using your own notes.

There is no account to create, no email address to confirm and no subscription to activate. The application works offline from the moment setup finishes.

🤝 Share One Memory Across Every AI App

openmymemo speaks a shared standard called MCP, which stands for Model Context Protocol. In everyday terms, that means many different AI applications already know how to talk to it. You connect each app once, and from then on it reads and writes to the same folder as every other app.

The applications people connect most often include Claude and Claude Code, Codex, Cursor, Gemini CLI and any other MCP-compatible tool. Each of them sees the same memories, in the same order, with the same details. When one app learns something new, the others know it the next time you open them.

If you use Obsidian or another note-taking program, you can point it at the same folder and read your AI memory as normal notes. The files are plain Markdown, so they display cleanly with headings, lists and links, and they remain readable even in a basic text editor.

📂 See Every Change and Undo Anything

Every time an AI writes to your memory, openmymemo records what changed. You can review the list of edits, open any single change side by side with the version before it, and decide whether it should stay.

If an assistant stores something inaccurate, you can undo that one change without touching anything else. Memory is not all or nothing here. You can delete a wrong fact, restore an older version of a note, or roll back a whole day of updates if you prefer. Your memory folder also keeps older copies of files, so a mistake made by any app is never permanent.

Because the files are plain text, you can also edit them yourself. Fix a typo, add a preference the AI missed, or write a note directly for your assistant to read. It is simply a folder of documents that you and your AI share.

🔒 Privacy You Can Verify

Everything openmymemo stores stays on your computer. There is no cloud copy, no sync server and no analytics service watching what you remember. It runs locally, so it keeps working when your internet connection does not.

Privacy claims usually ask you to trust a company. Here the situation is different, because you can open the folder and read exactly what is stored. If a sentence should not exist, delete it. If you want a full backup, copy the folder to another drive or an encrypted archive. If you want to start fresh, remove the folder and create a new one.

The application itself is open source, which means the code that reads and writes your memory can be inspected by anyone. Nothing about the way it handles your information is hidden behind a confidential agreement.

🧩 What You Can Do With It

  • Keep a consistent assistant across tools. Ask a question in one app and follow up in another without repeating your background.
  • Store long-running project context. Let your assistant remember goals, decisions and open questions for a project that lasts months.
  • Save personal preferences once. Writing style, working hours, tool choices and formatting habits are remembered everywhere.
  • Browse memory like notes. Open the folder in Obsidian or any editor and read it like a knowledge base.
  • Review before you trust. Check what an assistant decided to remember, and remove anything you did not intend to store.
  • Back up and migrate easily. Copy the folder to a new computer and your AI memory comes with you.

❓ Common Questions

Do I need to know how to code?

No. You download the application, open it, pick a folder and press a copy button for each AI app you use. Nothing requires typing commands or editing configuration files by hand.

Will this work if I only use one AI assistant?

Yes. Even with a single assistant, you gain the ability to read every memory it stores, edit those memories directly and undo any change you dislike. The sharing feature simply becomes available whenever you add a second app.

What happens to my memory if I uninstall openmymemo?

Nothing. Your folder stays exactly where it is, with every file intact and readable. You can keep using the notes with any text editor, or install openmymemo again later and reconnect to the same folder.

Does my information sync to my phone or another computer?

Only if you move it there yourself. Because the memory is a normal folder, you can copy it to any drive, place it in a folder your own backup software already handles, or store it on a personal cloud drive you control.

Where do I find new versions?

The same download page always shows the latest release at the top. Check it occasionally and download the newest version when one appears.
